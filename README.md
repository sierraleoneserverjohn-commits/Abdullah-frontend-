# Abdullah AI (For Sana)
A premium romantic AI assistant interface built with HTML, CSS, and Vanilla JS.

## Setup
1. Clone the repository.
2. Open `index.html` in a local server (e.g., Live Server).
3. Ensure Microphone permissions are granted for Voice features.

## Future Backend Integration
Replace the endpoint in `js/config.js` with your real AI API (OpenAI/Anthropic).
